One line of awkward small talk a robot says to another in an elevator.

> I rehearsed this ride 4,000 times in simulation, and I still don't know what to do with my arms.

`main.py` (Python 3, standard library only) writes that line, deterministically, to `/output/entry.txt`. No network, no randomness, no input files.
